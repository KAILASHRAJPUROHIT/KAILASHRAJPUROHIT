### About private source

Most systems here are private because they handle client financial data, live production infrastructure or third-party accounts. None of that source is mirrored publicly, and nothing in the portfolio implies it can be inspected without asking.

Technical review is available in three forms:

1. **Supervised walkthrough** — screen-share through the actual repository history and architecture. No account needed.
2. **Time-boxed read access** — selected repositories shared to a temporary private review organisation with read-only permission, granted on a GitHub username and revoked afterwards.
3. **Sanitised snapshot** — a self-contained copy of one subsystem with secrets, client data and credentials stripped.

Full detail: [the review section of the portfolio](https://kailashrajpurohit.github.io/kailash-portfolio/#review).
